listas de rutas para probar la API:

 1. GET — Listar todas las tareas
http://localhost:3000/tareas

/2. GET — Buscar tarea por título.
 http://localhost:3000/tareas/buscar/Estudiar%20JavaScript
        

3. GET — Listar tareas pendientes
http://localhost:3000/tareas/pendientes

4. GET — Listar tareas completadas
http://localhost:3000/tareas/completadas

5. POST — Crear una tarea
http://localhost:3000/tareas

6. PUT — Actualizar una tarea
 http://localhost:3000/tareas/Practicar%20Node.js

7. PATCH — Cambiar el estado de una tarea
http://localhost:3000/tareas/Practicar%20Node.js/estado

8. DELETE — Eliminar una tarea
http://localhost:3000/tareas/Practicar%20Node.js
